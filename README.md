# Orufy Technologies – Full Stack Developer Assignment

## Project Overview

This project was developed as part of the **Full Stack Developer Assignment for Orufy Technologies Pvt. Ltd.**

The goal of this assignment was to build a **fully functional website based on the provided Figma design** using modern full-stack technologies.

The application includes a **React frontend**, **Node.js + Express backend**, and **MongoDB database integration**. The UI is implemented according to the design and connected with backend APIs for dynamic data handling.

## Installation

### Clone Repository

git clone https://github.com/ranusaini031/orufy-technology.git
cd orufy-technology

---

### Run Backend

cd Server
npm install

Create `.env` file and add required variables.

Start backend server:

npm run dev

---

### Run Frontend

cd Client/client
npm install

Create `.env` file:

Start frontend:

npm run dev
